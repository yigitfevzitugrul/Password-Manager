# Secure & Encrypted Local Password Manager

This project is a modern desktop application built with a focus on maximum security using **end-to-end encryption**. Your data is never sent to any server; it stays strictly on your device, fully encrypted.

## 🛡️ Security & Features

*   🔐 **End-to-End Encryption:** All your data is secured with strong encryption algorithms (AES-256) before being saved to the database. Access is impossible without your master password.
*   🔒 **100% Local & Offline:** Your data never leaves your computer. Built on the "Zero-Knowledge" principle—we don't know your passwords, only you do.
*   🔑 **Master Password Protection:** Authentication and decryption rely solely on the master password defined by you.
*   🎲 **Strong Password Generator:** Generate complex, impossible-to-guess passwords to enhance your account security.
*   🌍 **Multi-Language Support:** Available in both English and Turkish.
*   🎨 **Modern Interface:** Sleek design with Dark/Light mode support for a comfortable user experience.
*   📝 **Secure Notes:** Store private notes for your accounts, encrypted just like your passwords.

## Installation & Setup

1.  Install dependencies:
    ```bash
    npm install
    ```

2.  Run the application in developer mode:
    ```bash
    npm run dev
    ```

3.  Build for production:
    ```bash
    npm run build
    ```
